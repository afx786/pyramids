# Pyramids --- Product Constitution

> Version: 1.0

## 1. Product Philosophy

### Vision

Pyramids is a builder-first collaboration platform where technical
credibility is earned through verifiable proof of work rather than
self-reported claims.

### Core Principle

> **Proof over Claims**

Every feature should answer one question:

**Does this increase trust through evidence?**

### What Pyramids Is

-   Builder identity platform
-   Project collaboration platform
-   Technical reputation system
-   Repository verification platform
-   Engineering discovery platform

### What Pyramids Is Not

-   Social media
-   LinkedIn clone
-   GitHub replacement
-   Discord server
-   Resume website
-   Portfolio driven by aesthetics

### Values

-   Evidence over popularity
-   Transparency over mystery
-   Consistency over novelty
-   Simplicity over decoration
-   Engineering quality over trends

------------------------------------------------------------------------

## 2. Design System

### Philosophy

The interface should disappear behind the work.

It should feel: - Calm - Minimal - Premium - Professional -
Trustworthy - Builder-first

Inspired by the philosophy of Linear, GitHub, Stripe, Notion, Arc
Browser and Apple.

### Colors

-   Warm neutral palette
-   Avoid pure black/white
-   Restrained accent
-   Comfortable for long sessions

### Typography

Primary: Inter

Accent: Instrument Serif (only for welcome messages, project titles and
milestone moments)

### Spacing

8-point spacing system: 8, 12, 16, 24, 32, 48, 64

Whitespace is intentional.

### Motion

-   150--200 ms
-   Natural easing
-   No bounce
-   Motion communicates state

### Core Components

-   Button
-   Card
-   Input
-   Select
-   Badge
-   Avatar
-   Modal
-   Drawer
-   Tabs
-   Table
-   Empty State
-   Loading State
-   Skeleton
-   Tooltip
-   Toast

Rule: Reuse components before creating new ones.

### Accessibility

-   Keyboard navigation
-   Visible focus states
-   Accessible contrast
-   Responsive layouts
-   Color-independent status indicators

## 3. Evidence System

The Evidence System is the foundation of trust inside Pyramids.

### Verification Seal

Binary trust state: - Verified - Pending - Failed

Appears on projects, profiles, repository reports and search.

### Repository Score

Objective repository quality score.

Breakdown: - Documentation - Code Quality - Testing - Structure -
Activity - Maintainability

Always explain the score.

### Verification Audit

Chronological engineering log: - Repository linked - Languages
detected - Technologies extracted - CI/CD detected - Docker verified -
Repository score generated

### Verification Timeline

Connect → Inspect → Analyze → Extract → Score → Verify

### Evidence Panel

Shows exactly why technologies were detected.

Includes evidence files and confidence.

### Confidence Indicator

Displays confidence for every detected technology.

### Verified Technologies

Repository-derived technologies.

Immutable.

### Verified Skills

Automatically extracted from verified repositories.

### Repository Metadata

Repository name, visibility, branch, size, license, language and
timestamps.

### Repository Statistics

Files analyzed, technologies, contributors and repository size.

### Contributor Card

Shows: - Role - Verified Skills - Current Rank - Repository Score
(optional)

### Opportunity Card

Shows: - Role - Required Skills - Experience - Weekly Commitment -
Availability

### Credibility Summary

Displays: - Verified Repositories - Verified Contributors - Extracted
Skills - Last Verification

# Rulebook

Every new feature must satisfy:

1.  Reinforces Proof over Claims.
2.  Surfaces objective evidence.
3.  Reuses existing components.
4.  Improves clarity.
5.  Increases trust.

------------------------------------------------------------------------

# Manifesto

Pyramids exists to help builders earn trust through verifiable proof of
work.

Every screen should reduce uncertainty.

Every interaction should communicate evidence.

Every component should reinforce credibility.

Beauty comes from clarity, consistency and restraint---not decoration.

**This is where serious builders prove what they can build.**
